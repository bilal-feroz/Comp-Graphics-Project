About this page

The 3D arcade cabinet, the camera zoom and this web page are a presentation extra, made for the wow factor. They are not part of the course requirements and are not what we hand in.

The game on the cabinet's screen is a JavaScript port of the team's Python program. It uses the same rules, figures, scene graph and matrix maths, and draws on a web canvas instead of OpenGL. Every member's part works the same way as in the Python version. The graded project is the Python + PyOpenGL + Tkinter program in the GitHub repository.
