ABOUT THE PROJECT

Four modules, one arcade cabinet

Our course project for Introduction to Computer Graphics: Breakout inside an arcade cabinet, drawn in 2D and 3D. Every object is a node in our own scene graph and is moved only with our own 3x3 and 4x4 matrices.

  • Python 3
  • PyOpenGL
  • Tkinter
  • Own 3x3 / 4x4 matrices
  • Scene graph
  • Timer-based animation
  • 42 passing unit tests
WOW FACTOR

The 3D arcade hall, the camera zoom and this web page are a presentation extra. They are not part of the course requirements and are not what we hand in.

The game on the cabinet's screen is a JavaScript port of the team's Python program, with the same rules, figures, scene graph and matrix maths, drawn on a web canvas instead of OpenGL. Every member's part works the same way as in the Python version. The graded project is the Python + PyOpenGL + Tkinter program in the GitHub repository.

One frame, start to finishWhat happens about 60 times a second in the Python program.

  1. InputKeys, mouse and sliders change the game's numbers.gui.py
  2. Rulesupdate(dt) moves the ball, checks collisions, keeps score.game.py
  3. AnimationThe numbers become each node's T · R · S.anim2d.py
  4. Scene graphworld = parent world · local, down the tree.scene.py
  5. MatricesOur own 3x3 / 4x4 maths, sent with glMultMatrixf.matrices.py
  6. Drawing2D raster algorithms, or 3D with light and a camera.render2d.py / render3d.py
